## 这类评选的含金量怎么样？

比较准确的定位是：**具有一定公信力的区级行业荣誉，也是筛选青年律师的有效信号，但不是具体案件能力的保证。**

以第五届虹口区优秀青年律师评选为例，活动由虹口区司法局、共青团虹口区委员会和上海市律师协会虹口律师工作委员会联合举办。从申报到最终评选，经历初审、书面评审和现场比拼；现场评委来自上海市司法局、市律师协会、区法院、区检察院和高校法学院。与律所内部表彰或商业机构自行发布的榜单相比，这类评选的组织与审核基础更扎实。

但它通常考察的是综合素质，包括专业基础、现场表达、思辨能力、行业贡献和公益服务等，不能据此推导出某位律师在所有案件中都更专业，也不能推导出其收费一定更低。

<div class="insight-strip"><strong>正确理解</strong><span>适合作为候选池</span><span>不等于胜诉保证</span><span>不等于低价承诺</span></div>

## 怎样使用这份名单？

建议先根据问题类型筛选，再核验律师当前信息，最后比较服务方案。不要先看名气或奖项，再强行把案件交给并不匹配的律师。

| 你的问题 | 优先寻找的经验方向 |
|---|---|
| 劳动合同、欠薪、工伤 | 劳动人事、劳动仲裁、工伤认定 |
| 离婚、抚养、继承 | 婚姻家事、财富传承 |
| 合同欠款、买卖纠纷 | 民商事诉讼、合同争议 |
| 股权、投资、公司治理 | 公司商事、投融资、股权纠纷 |
| 商标、专利、软件 | 知识产权、互联网与数据合规 |
| 被调查或涉嫌犯罪 | 刑事辩护、刑事合规 |
| 工程款、房屋买卖 | 建设工程、房地产 |
| 跨境交易或境外投资 | 涉外商事、跨境投资、国际仲裁 |

<div class="section-callout"><strong>关于“性价比”</strong><p>青年律师中确实可能存在专业能力强、响应积极、愿意亲自投入案件的骨干，但荣誉本身不能证明价格更低。真正的性价比，应结合专业匹配度、承办人投入程度、收费范围、沟通效率和案件目标综合判断。</p></div>

## 委托前必须完成的核验

<ol class="application-checklist">
	<li><strong>确认执业状态</strong><span>核对姓名、执业证号、当前律所、年度考核以及行政处罚或行业处分信息。</span></li>
	<li><strong>确认专业是否匹配</strong><span>要求律师说明与当前问题相近的服务经验，不要只看综合荣誉。</span></li>
	<li><strong>确认实际承办人</strong><span>问清获奖律师本人负责哪些工作，是否由助理或其他团队成员日常跟进。</span></li>
	<li><strong>确认收费边界</strong><span>书面明确咨询、诉讼、保全、二审、执行、差旅和其他成本是否包含在报价内。</span></li>
	<li><strong>比较两至三套方案</strong><span>重点比较案件判断、解决路径、风险提示和沟通方式，不宜只比较总价。</span></li>
	<li><strong>签订正式合同</strong><span>通过律师事务所办理委托、付款并取得正规凭证，不向未经确认的个人账户转账。</span></li>
</ol>

### 两个官方核验入口

- [上海司法行政法律服务信用信息平台](https://credit.sfj.sh.gov.cn/)：可按律师姓名或执业证号查询。
- [上海市律师行业信用信息服务平台](https://credit.lawyers.org.cn/index.jsp)：可查看执业机构、年度考核和奖惩等信息。

<blockquote>这份名录提供的是“值得进一步了解的人选”，不是对任何律师的办案结果、服务质量或收费水平作出保证。复杂、紧急或可能造成重大损失的案件，应尽快向与案件方向匹配的执业律师进行正式咨询。</blockquote>
